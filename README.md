# IPL 2022 Data Analysis

This project analyzes IPL 2022 match data using Python and popular data analysis libraries.

## Tools & Libraries

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Topics

* Dataset Understanding
* Data Cleaning
* Match-Winning Analysis
* Toss Decision Trends
* Toss Winner vs Match Winner
* Runs vs Wickets Victories
* Player of the Match Analysis
* Top Individual Scores
* Best Bowling Figures
* Venue Analysis
* Custom Insights
* Data Visualizations

## Key Insights

The project explores team performance, player performances, toss trends, winning patterns, venue distribution, and important match-level statistics from IPL 2022.

## Dataset

The dataset contains IPL 2022 match-level information including teams, venues, toss decisions, scores, match winners, player performances, and bowling figures.

## Project Purpose

This project was created to practice and demonstrate practical skills in:

* Data Cleaning
* Data Analysis
* Data Visualization
* Exploratory Data Analysis (EDA)
* Python Programming
